# dataviz-posit

A presentation developed as training for conference speakers.

The presentation was developed using Quarto/reveal.js. As is generally (always?) the case for this repo owner, the SCSS for such an endeavor starts out pretty clean and simple, but then gets a slew of one-offs over the course of the development and goes a bit off the rails.

Three separate presentations:

- `dataviz-best-practices.qmd`—this and all of the `_0x...` files are the main presentation

- `normative-conformity.qmd`—a brief riff on why so many presentations are so bad in corporate life

- `mckinsey-titles.qmd`—a slightly deeper dive on slide titles

Rendered presentation(s) from this repo are available on GitHub Pages at <https://gilliganondata.github.io/dataviz-posit/#/>.
